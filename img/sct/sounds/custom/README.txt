Your own combat text sounds (pfUI Octo)
=======================================

Put .wav or .mp3 files in this folder, then type the file name (for example
finishhim.mp3) into one of the four "Your sound" boxes in /pfui:
Combat Text > Crits & Sounds. They appear in every sound list as
"Your sound 1" to "4".

The game reads new files only after it restarts (not after /reload).
